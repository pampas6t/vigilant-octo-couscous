# Simple Calculator

A lightweight, responsive calculator built with plain HTML, CSS, and JavaScript. No dependencies or build tools are required.

## Run it

Open [`index.html`](index.html) in a web browser.

## Features

- Addition, subtraction, multiplication, and division
- Decimal and sign-toggle controls
- Clear and backspace controls
- Keyboard input support
- Responsive layout

## Keyboard shortcuts

| Key | Action |
| --- | --- |
| `0`–`9` | Enter a digit |
| `.` | Decimal point |
| `+`, `-`, `*`, `/` | Choose an operation |
| `Enter` or `=` | Calculate |
| `Backspace` | Delete the last digit |
| `Escape` | Clear |
